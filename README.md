# CRISPR·CAS9 — maquette interactive

Maquette pédagogique en français pour présenter le fonctionnement de CRISPR-Cas9, ses applications, ses limites et une idée de rubrique éditoriale.

## Aperçu

Une fois GitHub Pages activé, le site sera accessible à l’adresse :

https://floskinou.github.io/crisprcas9/

## Contenu

- `index.html` : prototype responsive, animation WebGL avec Three.js et explications pédagogiques.
- Les titres de blog sont des sujets de démonstration, pas des articles publiés.
- La veille quotidienne et la génération/publication automatique ne sont pas encore configurées. Le concept prévoit une relecture humaine avant publication.

## Prévisualisation locale

Ouvrir `index.html` dans un navigateur récent. Une connexion Internet est nécessaire pour charger Three.js et les polices web.

> Prototype en cours de conception. Contenu informatif, ne constituant pas un conseil médical.
